Intelligent honeypot

I built a decoy system that looks like a real, vulnerable server. When attackers try to break in, it records what they do, and my analysis spots patterns in their behavior.

Deployed Cowrie and Dionaea honeypots in a VirtualBox lab, centralized logs in an ELK Stack, and analyzed attack data with Python and scikit-learn.

Cowrie · Dionaea · ELK · Python · scikit-learn

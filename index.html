Projects

Internships and hands-on projects, from airport application security to honeypots and intrusion detection. Each one shows a different side of security.

Application security internship at ONDA

At Morocco's airports authority (July to August 2026), I checked the web application behind the airport's Security Management System for weaknesses, on a safe test copy, and told the team which to fix first.

Audited a PHP/MariaDB web application: STRIDE threat modeling, SAST (PHPStan, SonarQube, Semgrep), DAST (Burp Suite, OWASP ZAP), manual validation of findings, OWASP Top 10 risk prioritization and remediation recommendations. Tested on an isolated sandbox with fictitious data.

STRIDE · SAST · DAST · Burp · ZAP

Secure access gateway at TGR

At Morocco's national treasury (internship), I compared access-control products and set up one tightly controlled doorway that administrators use to reach internal servers, instead of connecting to each one directly.

Benchmarked PAM solutions, deployed Apache Guacamole as a secure administration bastion, and wrote MyBastion, an internal Bash tool: SSH bastion with password + TOTP authentication, role-based menus, ACL checks, replayable session recordings and audit logs.

PAM · Apache Guacamole · Bash

Cloud VM security analysis

I simulated attacks against virtual machines in the cloud and trained a model on a public dataset to recognize intrusions automatically.

Simulated attacks on cloud VMs, then trained and evaluated a Random Forest on the CICIDS2017 dataset (precision, recall, F1) for intrusion detection. Wazuh/Kibana integration designed as a next step.

Random Forest · CICIDS2017

Honeypot lab

I built decoy systems that look like real, vulnerable servers. When simulated attackers try to break in, they record what the attackers do, and I study it in a dashboard.

Deployed Cowrie and Dionaea honeypots on an isolated virtual network (honeypot, Kali attacker and ELK supervision VMs), simulated attacks with Nmap, Hydra and Metasploit, and analyzed the logs in Kibana with GeoIP enrichment.

Cowrie · Dionaea · ELK · Kali

OWASP Juice Shop: YARA code scanner

Juice Shop is a deliberately vulnerable web shop used for training. In a team project, we built rules and a scanner that flag risky code, and a pipeline that runs these checks automatically.

Team project (DevSecOps approach): I wrote the YARA rules and a Python scanner that recursively analyzes the app's code for patterns such as hardcoded secrets, injections and eval(), and the scanner was integrated into a CI/CD pipeline.

YARA · Python · CI/CD

SafeHer, a secure mobile app

Android development with Firebase, access control, certificate pinning and application-level protections.

Android · Firebase
